# API:
Any API can be of four types 
1) GET -> Read
2) POST -> Create
3) PUT -> Update
4) DELETE -> Delete

APIs generally start with api/version/products

Browser can check only get request. to check other three request type we require frontend or third party api tester like postman, thunderclient, echoapi
